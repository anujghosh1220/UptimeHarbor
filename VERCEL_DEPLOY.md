## Vercel Deployment (Manual, Free)

1. Go to https://vercel.com/new and import https://github.com/anujghosh1220/UptimeHarbor
2. Framework Preset: Vite (auto-detected)
3. Build Command: `cd frontend && npx vite build` or as detected
4. Output Directory: `frontend/dist`
5. No environment variables required for local-style demo
6. Deploy

Notes: In-memory storage; data resets on cold starts. Free Hobby plan limits apply.
